# Sources et traçabilité

**Statut :** Draft  
**Version :** 0.1

## Sources fondatrices

1. Brief Markdown original fourni par le porteur du projet.
2. Classeur Excel comprenant notamment « Données à saisir », « Plan financier SUCCESS » et « Besoin ».
3. Décisions validées dans les échanges produit.
4. Sources réglementaires officielles liées aux Country Packs.

Les fichiers originaux sont conservés en lecture seule dans un espace dédié et ne sont pas modifiés.

## Registre d’exigence

Chaque exigence structurante reçoit :

- identifiant;
- source;
- formulation;
- domaine;
- priorité;
- statut;
- critères d’acceptation;
- documents et composants concernés;
- tests;
- décision de remplacement éventuelle.

## Traçabilité Excel

Pour chaque cellule ou plage métier pertinente :

- classeur, feuille et adresse;
- libellé;
- entrée ou sortie;
- type et unité;
- formule;
- dépendances;
- équivalent Lalanda;
- cas de test;
- commentaire métier.

## Conflits

Lorsqu’une source contredit une autre :

1. ne pas choisir silencieusement;
2. documenter les deux formulations;
3. évaluer l’impact;
4. obtenir une décision;
5. créer un ADR ou une décision produit;
6. mettre à jour la matrice.

## Données sensibles

Les cas de référence sont anonymisés. Aucun document d’identité, secret, donnée bancaire réelle ou information personnelle inutile n’est commité.
